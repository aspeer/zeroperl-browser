# Browser examples

From the repository root, run `npm install` once. Use Node.js 22 or newer.
Each example builds to its own `dist/` directory. `dev` builds and serves it;
open the URL it prints. Generated sites require HTTPS or localhost.

- [hello](hello/): one PSP page with a Perl expression.
- [basic](basic/): navigation, forms, assets, interpreter state and SSE.
- [pagi](pagi/): a standalone asynchronous PAGI application returning HTML.
- [fortune](fortune/): prepare and run an unchanged Fortune application checkout.

The commands use the browser package in this checkout. For your own project,
see the installation instructions in the [main README](../README.md).
